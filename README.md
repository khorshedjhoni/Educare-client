# Educare – Community Development & Event Management Platform

**Live Website:** https://educare-client.vercel.app

## About the Project

Educare is a community-focused event management platform designed to bring people together through social development activities. The platform helps users organize and participate in meaningful initiatives such as free book distribution, educational programs, free tutoring, and donation campaigns.

Our mission is to make community involvement easier and create opportunities for everyone to contribute to a better society.

## Key Features

- **User Authentication:** Secure registration and login using Better Auth, including social login options.
- **Upcoming Events:** Explore upcoming community events and discover opportunities to participate.
- **Create Events:** Authenticated users can organize and publish new social development events.
- **Manage Events:** Event creators can update or delete their own events.
- **Join Events:** Logged-in users can participate in events that interest them.
- **Joined Events Dashboard:** Users can view and keep track of the events they have joined.
- **Event Details:** View detailed information about each event, including descriptions, dates, locations, and images.
- **Responsive Design:** Enjoy a user-friendly experience across desktop, tablet, and mobile devices.
- **Dark and Light Mode:** Switch between themes for a comfortable browsing experience.

## Getting Started

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/khorshedjhoni/Educare-client
   ```

2. Navigate to the project directory:
   ```bash
   cd educare
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Create a `.env.local` file and configure the required environment variables.

5. Start the development server:
   ```bash
   npm run dev
   ```

6. Open your browser and visit:
   ```text
   http://localhost:3000
   ```
